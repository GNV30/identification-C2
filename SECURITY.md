# Security Policy

Проект предназначен для defensive security, обучения и анализа собственных сетевых данных.

## Что не нужно публиковать

- реальные PCAP-файлы без очистки;
- внутренние IP-адресные планы компаний;
- домены и URL частной инфраструктуры;
- токены, ключи, cookie и учетные данные;
- персональные данные пользователей.

## Ответственное использование

Инструмент не выполняет эксплуатацию уязвимостей, не сканирует чужие сети и не расшифровывает трафик. Используйте его только на данных, которые вы имеете право анализировать.
